# Digital Forensics Evidence Tracker

## Project Description
The Digital Forensics Evidence Tracker is a Python-based project designed to record, manage, search, and verify digital forensic evidence.

## Features
- Add new evidence records.
- View all saved evidence records.
- Search for evidence records.
- Calculate the SHA-256 hash of a file.
- Store evidence records in a JSON file.

## Technologies Used
- Python 3.13
- JSON
- SHA-256 hashing
- IBM Bob
- Windows PowerShell

## Requirements
Python 3.13 or a compatible Python 3 version. The project uses Python's built-in modules and does not require external packages.

## How to Run
1. Open the project folder in a terminal.
2. Run `py -3.13 main.py`.
3. Follow the menu options displayed on the screen.

## Data Storage
Evidence records are stored in `evidence.json`.
